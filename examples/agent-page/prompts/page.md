照 `outline.md` 的大纲做一个单页介绍网页，写进 `index.html`。

输出语言：{{inputs.language}}（zh = 中文，en = English）。网页上的文字都用这个语言。

要求：

1. 单个 HTML 文件，样式写在 `<style>` 里。**不要任何外部资源**：不要外部脚本、样式表、字体、图片或 iframe，也就是不要出现 `http://`、`https://` 或 `//` 开头的 `src` / `href` 资源。需要图标就用 emoji 或内联 SVG。
2. 有 `<title>`，`<html lang="...">` 跟输出语言一致：zh 写 `zh-CN`，en 写 `en`。
3. 手机和电脑都好读：内容最大宽度约 720px，行高舒适，浅色和深色模式（`prefers-color-scheme`）都看得清。
4. 内容完全照大纲，可以润色句子，但不要加大纲里没有的事实。

只写 `index.html` 这一个文件，不要改别的文件。
