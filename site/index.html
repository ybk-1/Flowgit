万物皆可流程化。

Turn anything into a flow.

把一件事拆成一步一张卡片：每一步有自己的产物和版本，可以由模型、脚本、agent、HTTP 服务或你自己来做。改了其中一步，后面需要重跑的地方会自动标出来，你手改过的内容永远不会被覆盖。 Break any piece of work into stages, one card each. Every stage keeps its own outputs and versions, and a model, a script, an agent, an HTTP service or you can do it. Change one stage and the ones that need a re-run are marked for you; your hand edits are never overwritten.

flowgit init
短视频：为什么猫喜欢纸箱 Short video: why cats love boxes ~/my-video/flow.json

点一个阶段看详情 / click a stage for its details

按住 1 秒才会运行；按住时看板先预演每一步会怎样，提前松手就取消。/ Hold for a second to run; while you hold, the board previews what each stage will do, and letting go early cancels.

为什么要做成流程

Why make it a flow

runs/storyboard/4/

每一步都有版本

每次运行都存成一个版本。flowgit diff storyboard 3 看第 3 版和现在差在哪，不满意就 flowgit restore storyboard 3 回去。

Every run is saved as a version. flowgit diff storyboard 3 shows what changed since version 3, and flowgit restore storyboard 3 takes you back.

llm · script · agent · service · human

人和 AI 一起做

写脚本交给模型，剪辑交给 FFmpeg 脚本，查数据交给你自己的 HTTP 接口，挑素材留给你。每张卡写清楚由谁来做。

A model writes the script, an FFmpeg script edits, your own HTTP endpoint looks things up, and you pick the footage. Each card says who does it.

--model deepseek/deepseek-v4-pro

接任何模型和 agent

Claude、GPT、DeepSeek、GLM、Kimi、通义千问、本机 Ollama；也能把一步交给 Claude Code、Codex、Cursor 或 Gemini CLI。开着 VPN 或代理也能直接连，每次调用都显示用了多少 token。

Claude, GPT, DeepSeek, GLM, Kimi, Qwen or a local Ollama, and any stage can go to Claude Code, Codex, Cursor or Gemini CLI. It works behind a VPN or proxy as is, and every call shows how many tokens it used.

flowgit doctor

跑之前先检查

doctor 列出缺的密钥、命令和 agent；run all --dry-run 先说会跑哪几步、最多调用几次模型，什么都不花。

doctor lists missing keys, programs and agents; run all --dry-run says which stages would run and at most how many model calls, without spending anything.

浏览器里的看板

A board in your browser

看和改view, edit
文本产物直接在页面上改；照片、素材拖进人工阶段的文件夹。Edit text outputs on the page; drop photos and footage into a human stage's folder.
运行run
跑一个阶段或者全部，每一步的进度实时显示。Run one stage or all of them, with each step's progress shown live.
填输入inputs
主题、平台、语言这些流程输入在页面上填，保存前先检查。Fill in flow inputs such as topic, platform and language; they are checked before saving.
历史和回退history
每个版本都能和现在的文件对比，一键回到旧版本；你手改的内容会先存成一个版本。Compare any version with the current files and restore it in one click; your hand edits are saved as a version first.
只在本机local only
只监听 127.0.0.1，接口要带口令，别的网页碰不到它。It listens on 127.0.0.1 only and its API needs a token, so other web pages can't reach it.

flowgit init -t research-report

调研报告 Research report

子问题 → 资料（你） → 提纲 → 报告 → 检查出处

把一个问题拆开，写成带引用的报告，再用脚本检查每个结论有没有出处。

Break a question into parts, write a cited report, then check that every claim has a source.

flowgit init -t job-application

材料（你） → 匹配分析 → 简历 ∥ 求职信 → 检查

对照一份职位描述改简历、写求职信，两份并行写，最后检查关键词和没填的占位符。

Tailor a resume and a cover letter to one job description, written in parallel, then check keywords and leftover placeholders.

flowgit init -t support-sop

把产品资料整理成客服规程，用对话用例找缺口，最后打包成一份可评测的 SKILL.md。

Turn product notes into a support SOP, find gaps with sample conversations, and package an evaluable SKILL.md.

一个流程就是一个文件夹

A flow is a folder, so you can share and fork it

my-video/
├── flow.json        # 阶段和输入 / stages and inputs
├── prompts/         # 提示词 / prompts
├── scripts/         # 剪辑、导出 / edit, export
├── script.md        # 产物 / outputs
├── storyboard.json
├── final.mp4
└── runs/            # 每一步的历史版本 / history
    └── storyboard/4/
# 复制一份能分享的：默认不带产物，发现密钥就不写
# a copy that's safe to share: no outputs by default,
# and it refuses to write if it finds a key
flowgit share ../cat-video-share

# fork 别人放在 Git 上的流程，记下来源和 commit
# fork a flow from Git; the source and commit are recorded
flowgit init my-copy -t https://github.com/someone/cat-video

# 导出成 Skill，让 agent 按阶段跑
# export a Skill so agents can run it stage by stage
flowgit export-skill -o SKILL.md

几条命令开始

Start in a few commands

# 需要 Node.js 22+ / needs Node.js 22+
npm install -g flowgit           # 即将发布到 npm / coming to npm soon
flowgit templates                # 有哪些模板 / see the templates
flowgit init my-video
cd my-video
flowgit inputs set topic="为什么猫喜欢纸箱"
flowgit doctor                   # 先检查密钥和 FFmpeg / check keys and FFmpeg first
flowgit run all --dry-run        # 预演：会跑哪些阶段、调用几次模型 / preview: which stages run, how many model calls
flowgit run all
flowgit board                    # 在浏览器里看、改、对比 / view, edit and compare in the browser
flowgit log                      # 整个流程的历史和 token 合计 / the whole history and token total
