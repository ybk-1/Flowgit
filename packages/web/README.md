# @flowgit/web

Flowgit 的本机网页看板：一个只监听 `127.0.0.1` 的 `node:http` 服务器，加上 `public/` 里的静态页面（不需要网络，也不用 CDN）。一般通过命令行 [`flowgit board`](https://www.npmjs.com/package/flowgit) 打开。

The Flowgit local web board: a `node:http` server that listens on `127.0.0.1` only, plus a static page in `public/` (works offline, no CDN). Usually opened with the [`flowgit board`](https://www.npmjs.com/package/flowgit) command.

```js
import { startBoard } from "@flowgit/web";

const board = await startBoard({ dir: "my-flow", port: 0 });
console.log(board.url);
```

在看板上可以查看和修改产物、填写流程输入、运行阶段（同时只跑一个），也可以看历史版本、对比和回退（回退前会先保存手改），以及新增和删除阶段。顶部可以在卡片和流程图之间切换；流程图的布局来自 `GET /api/graph`（`layoutFlow`），浏览器自己画，不需要网络：默认用 CSS 3D 画成倾斜地面上的 2.5D 方块（可以运行的方块轻轻浮动，通向正在运行阶段的连线会流动），也可以在流程图右上角切回平面的 SVG，选择存在 localStorage 里。「预演 / Preview」调用 `GET /api/plan`（`planRunAll`），在日志里列出每个阶段会跳过、运行、等你还是不能运行，以及最多调用几次模型，同样的结果也标在卡片和流程图上（Esc 收起），什么都不运行。「全部运行」要按住 1 秒：按住时先显示同样的预演，按满才运行，提前松手什么都不运行；轻点和以前一样，会调用真实模型时先确认。界面一次只显示一种语言：右上角「中文 / EN」切换，选择存在浏览器的 localStorage 里，第一次打开跟着浏览器语言（`zh-*` 显示简体中文，其他显示英文）。文案在 `public/i18n.js` 的两份词典里，经由 [i18next](https://www.i18next.com)（MIT，从依赖包里以 `/vendor/i18next.js` 提供，不需要网络）；服务器和流程文件里的双语文字（“中文 / English”）只显示当前语言那一半。加一种语言就是在 `i18n.js` 里加一份词典。动效（状态解码、按住运行、跟着正在跑的阶段滚动、侧栏圆形展开、唱片式的历史版本，以及卡片跟着鼠标倾斜、流程图地面跟着鼠标转动，这两个只在用鼠标时有）在 `public/fx.js` 里，比 `app.js` 先加载，系统打开“减少动态效果”时都会关掉。卡片的立体感（分层阴影、高度表示状态、立体编号、像键帽一样按下去的按钮）只用 CSS。`GET /api/usage`（`flowLog`，和 `flowgit log` 不写阶段是同一个函数）按阶段合计 token，卡片、流程图提示和页面顶部都会显示。`POST /api/stage` 调用 `addStage`，再按 `flowgit validate` 检查，不通过就返回双语错误列表并且什么都不写；llm 的提示词文件不存在时会建骨架。`DELETE /api/stage?id=<id>` 调用 `removeStage`，还有依赖且没有 `force=1` 时返回 409 并点名，不删产物和 `runs/`。运行中这两个接口返回 409。文件变化时 SSE 会推送 `flow:changed`，看板立刻刷新。每个 `/api/*` 请求都要带启动时生成的令牌（`X-Flowgit-Token`；运行日志和 `flow:changed` 的 SSE 流 `/api/events` 用查询参数 `token`），`Host` 也只能是 `127.0.0.1` 或 `localhost`。页面本身只在带 `?token=` 的链接里拿到令牌：`startBoard` 返回的 `url` 就是这个链接，直接打开 `/` 只会看到提示。卡片上每个产物有缩略图：`GET /api/thumb?stage=<id>&output=<index>` 返回图片原文件（带 `ETag`，svg 的 `Content-Security-Policy` 是 `sandbox`），有 ffmpeg 时把视频第 1 秒的帧缓存到 `.flowgit/thumbs/`，没有 ffmpeg 时返回 204；有 ffprobe 时音频返回时长。文本、JSON 和文件夹仍用 `/api/file` 在卡片上预览。点缩略图打开原来的产物侧栏。

On the board you can view and edit outputs, fill in flow inputs, run stages (one run at a time), browse, compare and restore versions (a hand edit is saved before a restore), and add or remove stages. A toggle at the top switches between cards and a flow graph. `GET /api/graph` (`layoutFlow`) supplies the layout and the page draws it, with no network: by default as 2.5D blocks on a tilted floor in CSS 3D (a stage that is ready to run bobs gently, and the edge into the running stage flows), or as a flat SVG, picked at the top right of the graph and kept in localStorage. "预演 / Preview" calls `GET /api/plan` (`planRunAll`): the log lists whether each stage would be skipped, run, wait for you or cannot run, and at most how many model calls, and the cards and the graph show the same marks (Escape clears them), without running anything. Run all is held for one second: the hold shows the same preview, the run starts when the hold completes, and letting go early runs nothing; a quick tap works as before and asks first when it would call a real model. The interface shows one language at a time: "中文 / EN" at the top right switches it, the choice is kept in the browser's localStorage, and the first visit follows the browser language (Simplified Chinese for `zh-*`, English otherwise). Strings live in two dictionaries in `public/i18n.js` and go through [i18next](https://www.i18next.com) (MIT, served from the dependency as `/vendor/i18next.js`, no network needed); bilingual text from the server and from flow files ("中文 / English") shows only the current language's half. Adding a language means adding a dictionary to `i18n.js`. The motion (states that decode into place, hold to run, scrolling to the running stage, a side panel that opens as a circle, history as a stack of discs, and, with a mouse only, the card under the mouse tilting toward it and the 3D graph's floor turning with it) lives in `public/fx.js`, loads before `app.js`, and turns off when the system asks for reduced motion. The cards' depth (layered shadows, height for state, extruded numbers, buttons that press down like keys) is CSS only. `GET /api/usage` (`flowLog`, the same function as `flowgit log` with no stage) sums tokens per stage; cards, the graph tooltip and the top of the page show them. `POST /api/stage` calls `addStage`, then checks the flow the way `flowgit validate` does; errors return a bilingual list and write nothing, and a missing llm prompt file gets a skeleton. `DELETE /api/stage?id=<id>` calls `removeStage`; dependents without `force=1` return 409 and are named, and outputs and `runs/` stay. Both routes return 409 during a run. When files change, the SSE stream pushes `flow:changed` and the board refreshes at once. Every `/api/*` request must carry the token generated at startup (`X-Flowgit-Token`; the `/api/events` SSE stream for the run log and for `flow:changed` takes it as the `token` query parameter), and the `Host` must be `127.0.0.1` or `localhost`. The page itself only gets the token through the link with `?token=`: the `url` that `startBoard` returns is that link, and opening `/` by itself shows a note instead. Each output on a card has a thumbnail. `GET /api/thumb?stage=<id>&output=<index>` returns an image file (with an `ETag`; svg uses `Content-Security-Policy: sandbox`), caches a video frame from 1 second in when ffmpeg is available (204 when it is not), and returns an audio duration when ffprobe is available. Text, JSON and folders are previewed on the card through `/api/file`. Clicking a thumbnail opens the existing output panel.

看板页面是浏览器原生 ES 模块（`<script type="module">`，没有打包）。入口是 `public/app.js`；所有 `/api/*` 请求和 SSE 都在 `public/api.js`。阶段卡片、产物面板、历史、流程图、流程输入和运行分别在 `cards.js`、`panel.js`、`history.js`、`graph.js`、`inputs.js`、`run.js`。新的产物查看器放在 `public/viewers/`，调用 `registerViewer` 注册。服务端路由在 `src/routes/`，`server.ts` 负责启动、令牌、静态文件和分发。`.js` 的类型是 `text/javascript`。

The board page is native browser ES modules (`<script type="module">`, no bundler). `public/app.js` is the entry; every `/api/*` request and the SSE connection live in `public/api.js`. Stage cards, the output panel, history, the graph, flow inputs and running are `cards.js`, `panel.js`, `history.js`, `graph.js`, `inputs.js` and `run.js`. New output viewers go in `public/viewers/` and register with `registerViewer`. Server routes live in `src/routes/`; `server.ts` starts the board, checks the token, serves static files and dispatches. `.js` is served as `text/javascript`.
