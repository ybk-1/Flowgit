# 插图 / Art

把插图放在这个文件夹里，文件名照 `art-brief.md` 写：

- 跨页：`p04-05.png`（第 4、5 页）
- 单页：`p32.png`（第 32 页）
- 封面：`cover.png`

PNG 或 JPEG 都可以。像素尺寸、出血和中缝的要求见 `art-brief.md`。印刷检查会量每张图的尺寸。

Put the art in this folder, named as `art-brief.md` says:

- A spread: `p04-05.png` (pages 4 and 5)
- A single page: `p32.png` (page 32)
- The cover: `cover.png`

PNG or JPEG. Pixel sizes, bleed and gutter are in `art-brief.md`. The print check measures every image.
