按金字塔原理组织 / Organize it with the Pyramid Principle:

1. 先写**核心结论**：一句完整的话，是一个判断或建议，不是一个话题（“把周报改成流程，每周省 2 小时”，而不是“关于周报”）。
2. 写 **SCQA 开场**：情境（听众已经认同的现状）→ 冲突（出了什么变化或问题）→ 问题（听众心里会问什么）→ 回答（就是核心结论）。
3. 列出支撑核心结论的 3 到 4 个论点，彼此不重叠、合起来能撑住结论。每个论点下面放 1 到 3 页证据。
4. 最后一页是明确的下一步：谁、做什么、什么时候。

1. Write the **governing thought**: one full sentence that is a claim or recommendation, not a topic.
2. Write the **SCQA opening**: situation (what the audience already agrees with) → complication (what changed or went wrong) → question (what they now wonder) → answer (the governing thought).
3. List 3 to 4 supporting arguments that do not overlap and together hold up the claim, each with 1 to 3 evidence slides.
4. The last slide is a clear next step: who does what, by when.

格式 / Format:

```
# <演示标题 / deck title>

**核心结论 / Governing thought**：……

**开场 / Opening (SCQA)**：情境……；冲突……；问题……；回答……

## 第 1 页：<这一页的结论，一句话 / this slide's claim, one sentence>
证据 / Evidence：<用什么证明：数据、例子、画面、引用 / what proves it: data, an example, a visual, a quote>
```

每页标题都写成一句结论，不超过两行；只写一页能讲完的一件事。数据只用你确定的或听众提供的，不确定的写成“需要补充的数据：……”。 / Every slide title is a one-sentence claim of at most two lines; one idea per slide. Use only data you are sure of or the audience gave; otherwise write "data to add: …".
