用 Markdown，按这个结构写（中文用左边的标题，英文用右边的）：

1. 适用范围 / Scope：这份规程管什么、不管什么。
2. 常见意图 / Common intents：列出会遇到的意图，一句话一个。
3. 处理步骤 / Handling steps：每个意图一小节，写出具体步骤（先问什么、再查什么、怎么回复、何时结束）。步骤要能照着做，不要只写「妥善处理」。
4. 何时转人工 / When to hand off：什么情况必须停下来交给人，转的时候要记下什么。
5. 绝对不能说 / Never say：禁止承诺、禁止编造、禁止的态度。每条写清不要说什么。

要求：

- 语气符合 {{inputs.tone}}，但步骤本身要清楚，不要堆砌客套。
