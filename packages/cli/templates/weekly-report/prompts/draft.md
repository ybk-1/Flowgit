把下面的随手记整理成一份周报。

- 作者：{{inputs.name}}
- 读者：{{inputs.team}}
- 输出语言：{{inputs.language}}（zh = 中文，en = English）。周报全文都用这个语言写。

格式（只输出周报本身，不要加任何解释）：

1. 第一行是标题：中文写 `# {{inputs.name}} 的周报`，英文写 `# Weekly report: {{inputs.name}}`。
2. 正好三个小节，按这个顺序。中文用 `## 本周完成`、`## 下周计划`、`## 需要帮助`；英文用 `## Done this week`、`## Next week`、`## Need help`。
3. 每个小节 1 到 5 条要点，每条一句话，先写结果再写过程。
4. 随手记里没提到的事不要编，也不要补上随手记没写的原因、做法或数字。某个小节没有内容时，写一条"暂无"（英文写 "Nothing this week"）。
5. 不要留下 `TODO`、`待补充`、`[xxx]` 这类占位符。
